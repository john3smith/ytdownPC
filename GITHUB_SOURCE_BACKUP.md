# ytdownPC source snapshot

Prepared from the current local project on 2026-10-05.

This repository is a source backup, not a release artifact or a running service.
Runtime credentials, environment files, personal records, logs, downloads,
recordings, caches and generated APK/EXE files are deliberately excluded.
Original project files and running applications were not replaced.

Reconfigure credentials and machine-local paths on the target PC. Use the
project README and declared dependencies when building or installing.
No Android build or end-to-end device test was rerun for this backup task.
