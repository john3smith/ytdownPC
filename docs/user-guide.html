YTDownPC

1.0.0 · 소스 기준Windows · Python GUI / CLI / MCP

공개 YouTube·Instagram·X 영상 링크를 Windows PC에 저장하는 프로그램입니다. 그래픽 화면 외에 명령행과 로컬 MCP로 다운로드 시작·상태 확인을 요청할 수 있습니다.

01

어떤 일을 하나요?

GUI

링크·저장 폴더·화질을 선택하고 진행률과 속도를 봅니다.

다운로드 엔진

yt-dlp와 FFmpeg로 영상·음성을 다운로드하고 병합합니다.

명령행

--probe로 정보 조회, --url·--quality·--output으로 다운로드를 지정합니다.

MCP

video_info, start_download, download_status 도구로 비동기 작업을 관리합니다.

02

처음 사용하기

  1. Python 가상환경을 만들고 requirements.txt를 설치합니다. 설치에는 인터넷이 필요합니다.
  2. 준비된 가상환경의 Python으로 ytdownpc.py를 실행합니다. YTDownPC.cmd는 해당 가상환경의 pythonw.exe를 사용합니다.
  3. 영상 링크를 넣고 best / 1080 / 720 화질과 저장 위치를 선택합니다.
  4. 다운로드를 시작하고 완료 상태와 실제 생성 파일을 확인합니다.
  5. MCP가 필요하면 가상환경 Python과 ytdownpc_mcp.py의 절대 경로를 stdio 서버로 등록합니다.
03

자주 쓰는 기능

저장 위치
기본은 현재 Windows 사용자의 Downloads입니다. 필요하면 다른 로컬 폴더를 지정하세요.
정보만 보기
--probe 또는 MCP video_info는 다운로드 전에 제목·영상 정보를 확인하는 용도입니다.
비동기 다운로드
MCP start_download가 반환하는 작업 ID를 보관하고 download_status로 실제 완료·실패를 확인하세요.
04

문제가 생겼을 때

명령창이 바로 닫힙니다
가상환경과 requirements 설치 상태, YTDownPC.cmd가 가리키는 실행 파일을 확인하세요.
파일이 아직 없습니다
start_download는 시작 확인입니다. 상태 조회와 최종 파일 검증이 필요합니다.
병합 실패
FFmpeg 경로와 저장공간, 파일 접근 권한을 확인하세요.
05

데이터와 보안

  • 로그와 출력 경로에는 사용자의 URL·파일명이 들어갈 수 있습니다. 다운로드 미디어와 로그를 저장소에 넣지 마세요.
  • 권한 있는 공개 콘텐츠만 저장하세요. DRM·유료·접근 권한 없는 자료의 우회를 지원하는 안내가 아닙니다.
06

알아두실 제한사항

  • README 기준 EXE Release가 아직 없으므로 실행파일이 게시되어 있다고 가정하지 말고 Releases를 확인하세요.
  • 사이트별 로그인·계정 전체 수집과 Android판 음원 토글은 PC판 기능이 아닙니다.
  • MCP는 한 번에 한 작업을 실행하고 상태를 메모리에 저장합니다. 서버 종료 후 자동 복원을 보장하지 않습니다.
  • 소스의 EXE 빌드 설정에 개발 PC 경로가 있으므로 다른 PC에서는 YTDownPC.spec를 검토해야 합니다.
07

소스 실행·검증

아래는 문서용 명령 예시입니다. 실제 실행에는 해당 README의 개발 환경·권한·의존성 준비가 필요합니다. 프로젝트 루트에서 사용하며 이 문서를 열기만 해서는 실행되지 않습니다.
